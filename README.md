# ninthember.com

Static site for Ninth Ember, hosted on GitHub Pages. No build step.

- `index.html` home page (studio, Crystal Road showcase with a live playable embed, contact)
- `privacy.html`, `terms.html` legal pages
- `assets/` stylesheet, script, self-hosted fonts (Syne, Inter under the SIL Open Font License), images

To add a new app: add a card to the "Our apps" grid in `index.html`, or copy the Crystal Road `showcase` block for a full feature.

Custom domain: after DNS points at GitHub Pages, set `ninthember.com` under Settings → Pages → Custom domain, which creates the `CNAME` file.
